# 股票研究 Dashboard 設計

日期：2026-11-04。狀態：待用戶確認。

## 目的與範圍

建立本機運行的全美上市普通股研究工具，掃描連續收市下跌及成交量遞減形態，以互動圖表、回測及 ML 排名檢驗研究假設。用戶已選完整研究版、Python 後端、React 前端，以及單一 Docker container 管理。這是一個研究工具，不連接交易下單。

## 方案

已選完整研究版：數據下載、掃描、圖表、回測及 ML 一起建立，以純規則作模型基準。另一個考慮過的方案是先做掃描及圖表，再加回測及 ML；工作較少，但無法立即評估訊號的預測價值。

## 運行架構（以下為建議的實作選擇）

- Python FastAPI API：6001；React + TypeScript 前端由 Nginx 提供：6002。前端以相對 /api 路徑經 Nginx 代理到 API。
- 同一個 container 以進程管理器運行兩個服務，處理退出及停止訊號。Docker Compose 一條指令啟動；預設僅綁定本機。
- SQLite 保存工作狀態、設定、掃描及實驗結果；Parquet 保存 OHLCV；/data 使用持久 volume。
- Alpaca key 僅由後端環境變數讀取，不傳給瀏覽器、不寫入日誌。未提供 key 時可使用有明確標記的固定種子示範數據；真實模式出錯不會偷偷改用示範數據。
- 大量下載、回測及訓練由背景工作執行，前端顯示進度、錯誤及取消控制。第一版限制同時一項重型工作，container 重啟後中斷工作標記為 interrupted，可重新提交。

## 介面與互動

繁體中文介面、深色金融研究風格，適配桌面及較窄螢幕。導覽分為總覽／掃描、股票詳情、回測、ML 實驗、數據管理。

掃描頁提供截至日期、下跌日數、縮量日數、最低價格、平均成交金額篩選；可搜尋、排序、分頁、匯出 CSV，點選股票顯示可縮放價量圖、訊號日期及特徵。預設三次收市下跌使用四個收市價，三日縮量使用三個成交量，按交易日而非日曆日計算。特徵包括多期回報、縮量比例、均線距離、波幅及流動性；缺失資料不補造有效訊號。

回測頁提供日期、持有期、止賺止蝕、每邊成本、持倉上限及資金設定。顯示資產曲線、回撤、交易列表、勝率及每筆回報。第三日收市確認訊號，最早下一交易日開市成交；交易成本計入入場及離場。若日線同時碰到止賺止蝕，保守假設止蝕先發生；跳空穿越止蝕以開市價計。持倉受現金及上限約束，重複訊號不會重複持有同一股票；尚未完整退出的樣本清楚標示或排除，不假設已實現回報。

ML 頁先提供 Logistic Regression 及一個樹模型，使用同一候選池與純規則比較。預設目標為從下一交易日開市入場、固定持有期後的扣成本正回報；止賺止蝕回測另呈現，避免混淆標籤。按日期切分訓練／驗證／測試，分界清除標籤跨界樣本；所有股票同日資料位於同一分段，預處理只在訓練資料擬合。顯示樣本數、日期、正例比例、PR-AUC、Top-K 命中率、基準及樣本外回測。未經校準的分數標示為排名分數；資料不足則拒絕訓練並解釋原因。預設不調參搜尋、不使用深度學習。

## 真實數據

Nasdaq Trader 兩份當前目錄建立股票池；過濾 ETF、測試證券及可識別的非普通股，保留過濾原因及更新時間。第一版不聲稱完全覆蓋 OTC 或完整歷史上市名單。

Alpaca SIP 1Day bars 批量查詢，完整處理 next_page_token、限速、重試、重複資料、改名及拆股調整。資料下載預設一年供原型使用，可選更長日期；每日增量更新並回補近期資料。根據紐約交易時區只使用已結束交易日，遵守免費 SIP 至少延遲 15 分鐘要求。保留調整設定、來源與抓取時間，價格與成交量調整保持一致。原始交易價格與研究調整價格的用途需明確區分，回測不混用兩種價格單位。

數據管理頁呈現股票池大小、日期覆蓋、缺失／失敗清單、下載狀態及重試。使用今日股票池回測會有生存者偏差；固定在結果顯示此限制。示範模式的收益及 ML 指標不得當成策略證據。

## 驗證與交付

覆蓋形態日期邊界、缺失值、跨標籤日期切分、無未來資料洩漏、下一日成交、跳空與同日雙觸發、成本及持倉資金約束。下載測試使用模擬分頁及錯誤；沒有 API key 不能聲稱驗證真實下載。檢查前端建置及核心互動，Docker 可用時建置並驗證兩個端口、健康狀態及 volume 保存；不可用時明確交代。

交付完整原始碼、Dockerfile、Compose、環境變數範本、繁體中文 README 及測試。無真實數據時仍能以示範模式端到端操作，不捏造已完成的實盤或樣本外成績。
